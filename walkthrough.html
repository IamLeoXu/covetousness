她的一生也要查。

B 是案件组合，P 是人生调查，N 是分类笔记。案件按三卷展开；同一时间，场景与证据池只显示当前卷。人物材料另收，不混进案件证据池。两条线都完成后，才能作最终评价。

三卷案件六段人生三条关系正反拼图结尾与播放台

01 / 案件最短路线

最初指控核实一项即可进入第二卷；第二卷需要危险告知与款项用途两项；第三卷需要行动、当时处境和因果界限三项。已完成的卷可以随时回看。

卷宗取得材料B 中选择的说法
01 最初的指控资料台：当晚入口录像摘录当晚至少一名现住客，持自己的钥匙自行离开
02 危险与告知资料台：完整报告；在查看窗口点 TURN PAGE 取得签收回执。前台：住客告示她收到停用要求，却没有完整传达给住客。放入报告、回执、告示三份
02 危险与告知录音室：临时安置拨款条件＋实际转账与余额安置款先支付了房租与旧维修欠款，改变了指定用途
03 救援与后果资料台：返身救人的录像摘录事故后，她确实返回受损区域，把澪抱了出来
03 救援与后果资料台：救援接线的完整指示。前台：奈央记录的掉落声她先接到接应指示，随后又听到掉落声，才决定返身
03 救援与后果资料台：第一次专业接手记录＋伤害因果的复核意见现有资料无法确认搬动增加了多少伤害，也无法确认绝对无害

每次提交后看完回应。第一项可用另外两条路线替代：前台旧钥匙＋退住登记 → 旧钥匙属于已退住的人；完整原通话＋首次报警记录 → “别走”发生于事故后、说给安置站值班员。

第二卷也可分步推断：报告＋回执 → 已收到停用要求；报告＋告示 → 告示省略了停用要求。切到“已核实推论”，把两个中间推论组合，仍可证明没有完整传达。人物档案不能用来替代这些证据。

02 / 六段人生调查

按 P，打开“经历核对”。左侧选一段；先打开“01 旧档”，再点“02 交谈与证词”。选能核对事实的问题，看完回答，补访即保存；点同一张卡可重读全文。之后在三种重建说法中选一项，点 VERIFY EVENT。一次只展示本段的两份来源。

经历补访该问什么核对事件的正确方向
16岁 / 下次先拆这个那些箱子是谁陪你收的，后来还联系吗？迁居不断，她用熟悉物件接续生活；家人的联系仍在。不能凭搬家认定被抛弃
19岁 / 两张不相邻的票那时候有什么事，是对方陪你做的？旧物和旁证支持真实、相互的亲密；后来分手不抹去当时的爱
20岁 / 两份不同日期你拒绝培训时，遥已经拿到外地录用了吗？三月拒绝培训、七月对方获录用、九月离城。她的自主选择在先；自主也会遗憾
21岁 / 没有读的最后一句分手后的探望，是双方重新约好的吗？分手信明确结束关系，后来行程未获确认。没有死亡，也没有继续恋爱的承诺
24岁 / 不包邮的针线纱纪离开时，你是怎么帮她结完那份工作的？她曾经舍不得仍帮助朋友离开，保留来往与自己的专业价值
26岁 / 迟接的电话母亲搬家后，她还邀请你过去吗？联系仍在。她越来越难容忍关系变化，这可解释恐惧，但不能使当下越界自动正当

带着“从小没人爱”“对方一直利用她”“所有人都抛弃了她”等假设提问，会被她纠正；不会丢档或扣掉进度，可以回去问一个可核对的问题。不能仅靠打开旧档就直接获得拼图片。

03 / 三条人生关系

在“关系推断”中，先选两个已重建的事件，再选读法，点 CONNECT。不是把“好人”和“坏人”算成分数；每条关系必须同时保留两边已核实的事实。

问题选择这两段正确读法
幸福与结束，能否同时是真的？19 两张不相邻的票＋21 没有读的最后一句亲密真实发生过，结束也已明确发生；二者不互相取消
没走的路，能向谁索还？20 两份不同日期＋21 没有读的最后一句她自主留下后确有遗憾，但不能把投入变成对方必须留下的债
她一直都只有这一种活法吗？24 不包邮的针线＋26 迟接的电话她曾能舍不得仍放手；如今更怕变化，弧光在这种转变中

两段事件的先后选择不影响核对。选错事件或读法会给出反馈，可以重试；这些侧写不进入案件证据池，不新增法律罪名，也不抵销伤者的损失。

04 / 正反人物拼图

完成六段事件与三条关系后，在“正反拼图”里把六片按年代放回。可点选再放置，也可拖放。错误位置可直接替换，碎片不会丢失。

位置左片右片
第一行16 下次先拆这个19 两张不相邻的票
第二行20 两份不同日期21 没有读的最后一句
第三行24 不包邮的针线26 迟接的电话

点 ASSEMBLE 确认一面，再切 SIDE A / SIDE B 看另一面。正面保留她被爱、爱人、做选择和成全朋友的经历，背面呈现她如何用单方面的“下一次”抵住结束。两面读过后，完整人物侧写才成立。

05 / 最后评价与处决 CG

案件三卷与完整人物侧写完成后，按 N，笔记底部点 MAKE YOUR JUDGMENT。HOLD 保留未来改变的可能，同时公开过错、支持外部接管与继续追责；RELEASE 承认真心和因果疑点，仍公开反对她再独立承担安置。两者共用事实。

断罪后看完反应对白，会进入完整磁带台。点击磁带放入并播放。手动 STOP 与自然播完后的自动 STOP 都进入待机黑屏，保留暗底色、固定颗粒、扫描细纹和玻璃反光；退带开盖后也保持此状态，磁带底噪停止。PLAY 的暂停保留当前画面，重新播放可恢复演出。顶部 RETURN TO CASE 返回调查，不会遗留 CG 音频。

HOLD 有独立尾声，也能不改变判断地预览 CG。进度自动保存；旧 v0.2 存档继承已核实的案件事实，新的人生调查需完成，旧版结局不会跳过新增内容。
