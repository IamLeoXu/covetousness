最初指控核实一项即可进入第二卷；第二、三卷可自由继续取材，不需要每卷查完才能播出。所有组合都按“CUE 预听确认 → ARM → REC”录下。修改来源会解除待命。已完成的卷可以随时回看。

02 / 六段人生调查

按 P，打开“经历核对”。左侧选一段；先打开“01 旧档”，再点“02 交谈与证词”。选能核对事实的问题，看完回答，补访即保存；点同一张卡可重读全文。原件底部的随附材料可继续点击。深入核对时，在“继续补访 / 重建这段经历”中选说法，点 VERIFY。只想采用片面侧写则读初始档案、点“收入侧写盘”，不必先做回访。

03 / 三条人生关系

两段有关经历都完成深入核对后，对应关系才出现在“关系推断”中。先选两个已重建的事件，再选读法，点 CONNECT。不是把“好人”和“坏人”算成分数；每条关系必须同时保留两边已核实的事实。

04 / 正反人物拼图

在“正反拼图”里，把已经取得的片段按年代放回。只放一片也可以采用，其他位置可留空；不必先完成全部事件或关系。可点选再放置，也可拖放。错误位置可直接替换，碎片不会丢失。

05 / 任意选轨，编排本期

  1. 录下第一条 TAKE 后按 R。任选一轨或多轨“接入 PGM”，A1、A2、A3、B 不需要全选。即使人生侧写完全空白，也可以收尾。
  2. 有一片采用的人物拼图，B 轨就可用。选择 A → B 或 B → A 改变实际顺序；人物原话下拉只显示你确实采用的片段。
  3. 选择最后一句针对“这次发生的事”，还是“她是怎样的人”。RELEASE 的评价范围会不同；未经核实的具体事实依然不会被程序认作成立。
  4. CUE 文字预听，只包含你接入的轨道。确认后进入最后一句，选 HOLD 暂缓裁决或 RELEASE 签发裁决。更改顺序、取舍、原话或评价范围，必须重新预听确认。
  5. ON AIR 按你的编排逐段播出；未发现的救援行动、恋爱、送行不会自动补进稿件。完成后回到录音室，可打开磁带，也可回台内继续翻原件。

播出时封存当时的事实、来源、已采用侧写、轨道、评价范围和原稿。之后翻到新材料不会改写此前的播出。N 导出记录可看到封存范围；R 可重读原稿。中途离开可从原段落继续。来电、采访与播出均为文字转录，配设备音效，没有演员对白录音。

06 / 播出之后与处决 CG

节目编排和文字预听确认后，进入最后评价。HOLD 暂缓最终裁决；RELEASE 依据本期采用的版本签发裁决。不是全知稿件，同一轨道内也只包含你实际核实的内容。

断罪版节目播完、看完她的反应对白后，可选择打开完整磁带台，或先返回台内继续取材。点击磁带放入并播放。手动 STOP 与自然播完后的自动 STOP 都先出现短促的十字收束闪光，再进入待机黑屏，保留暗底色、固定颗粒、扫描细纹和玻璃反光；退带开盖后也保持此状态，磁带底噪停止。PLAY 的暂停保留当前画面，重新播放可恢复演出。顶部 RETURN TO CASE 返回调查，不会遗留 CG 音频。

HOLD 有独立尾声，也能不改变判断地预览 CG。进度自动保存；v0.3 的案件与人生进度保留，首次继续会补放开场；旧版本未保存的播出稿不会被凭空补造。v0.2 的案件事实仍可继承，新增人生调查需完成。
