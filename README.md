# DEAD AIR · 她留下的东西 / 第一章整合版

独立整合版本 / v0.2。调查、对质、正反人物拼图、两种终局评价，以及完整处决 CG。无 AI、无安装依赖。

直接用 Chrome 或 Edge 打开本目录的 `index.html` 即可。也可以把本目录内全部文件作为静态网站上传到 GitHub Pages，无须构建、后端或 API Key。

## 怎么玩与攻略

完整逐步攻略：打开 `walkthrough.html`。案件结构、虚构事实时间线及真实判例参照：打开 `case-notes.html`。

1. 在录音室、小楼前台、资料台之间调查。打开的材料自动进入线索夹，报告可以翻到签收附页。
2. 按 B 或右下角的 BUILD AN ARGUMENT。选择一个说法，点击或拖入最多三份相关材料。
3. 提交后听小春回应。证据不足与过度推断有不同反馈；核实的推论可以再次作为材料组合。
4. 核实初始指控的一项、告知与资金、救援及因果界限，再拼完人物正反两面，进入最后的公开评价。

N 打开笔记，P 人物拼图，H 当前提示，1 / 2 / 3 切换地点，Esc 关闭窗口，Enter 继续对白。触屏可点击完成全部操作。进度自动保存在当前浏览器；菜单中可重新开始。

## 本次包含

- 三个地点，二十二份原始材料，事实核实与因果争议。
- 钥匙、当晚出入和电话三条初始调查路径。
- 原报告、签收和住客告示的第二轮对质，可直接组合，也可通过中间推论继续组合。
- 证据不足、与材料冲突、过度推断及成立的说法，各有预写回应。
- 两种公开评价，保留同一组已核实事实。
- 六片人生的正反拼图、随对质进程变化的常态/防御/动摇/痛哭立绘，生活访谈、自动存档与可复制记录。
- 断罪后接入 execution 内的完整处决磁带台；保留有独立尾声，仍可不改变判断地预览演出。

调查材料中的录音、录像使用明确标记的文字转录和复核摘录；处决 CG 包含现有完整歌曲、人物动画、波形、设备音效及自动退带。

## 素材与独立性

美术复用当前项目的背景、角色剪影、钥匙、信封和磁带装饰。所需文件均已复制到本目录的 assets 内，网页没有引用上级目录或 DEAD_AIR_CG。

本目录不依赖外面的两个旧项目。原 DEAD_AIR_CG 与 DEAD_AIR_INQUIRY_DEMO 保持原样，增量修改仅在此目录。测试脚本、前后哈希与测试图片位于工作区的 assets_all 中，不需要上传。
