# DEAD AIR · 她留下的东西 / 第一章 v0.5

深夜电台来稿、组合追问、人物档案、选轨编排与处决磁带的独立 HTML5 原型。

打开 index.html。部署 GitHub Pages 时，复制本目录的全部内容，包括 assets、execution 和 .nojekyll。无需构建、后端、API 或上级目录依赖。

## 本次变化

- B 编辑台有实际的 CUE → ARM → REC 顺序，修改来源会解除待命。首次组合由六步导播便签引导到提交。
- 核实一项说法或采用一块局部侧写就可准备裁决。完整案件与六段人生都不是结局门槛。
- 原件可继续点随附材料。分手行程 → 原信 → 票根；培训回函 → 结算索引 → 寄件回单。更深的恋爱、专业与友情从这些路径发现。
- R 播出单任意选轨接入 PGM，只播选中的已知材料。最后一句可针对本次行为或扩大到整个人，不自动补入未知事实。
- 播出时封存取材范围、侧写片段、轨道与原稿；后续发现不改写既有节目。这份记录供后续叙事使用，不弹道德评分。
- 保留石墨、荧光绿和紫色，增加珊瑚红的录音总线、设备按键、导播提示与采用轨道。

## 操作与攻略

B 编辑台，P 人物档案，N 笔记，R 播出单，H 分阶段提示，1 / 2 / 3 取材区。鼠标与触屏均可完成全部核心操作。详细组合、完整重建及附页路径见 walkthrough.html。

首次教学：读原通话、调首次报警记录，在 B 选“别走发生在事故后”，放入这两个来源，CUE 确认，ARM 待命，REC 录下回答。现在即可编排收尾，也可继续取材。

## 演出与存档

CG 歌词时间、动画、背景、配色与音频沿用原版；小春继续只用 shadow / detail 无五官素材。STOP 和自然结束先 CRT 十字收束，再留下带暗磷光、固定颗粒、扫描细纹与玻璃反光的待机黑屏。自动退带、开盖后仍待机，暂停保留画面。

电话、采访与播出为文字转录配设备音效；处决 CG 含原有完整歌曲和设备声。沿用 dead-air-chapter01-v03 存档键，接受 v0.4 / v0.3 / v0.2 旧进度。已有完整侧写保留，播出中可继续原稿。

原 DEAD_AIR_INQUIRY_DEMO 未改。独立 DEAD_AIR_CG 按本次要求只同步关屏/停止/退带/待机效果，保留独立播放器界面。本章 execution 仍作为章节内播放子页。开发检查与历史快照在工作区 assets_all，无需上传。
