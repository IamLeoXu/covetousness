# DEAD AIR · 余声 / 第一章 v0.12.1

静态 HTML5 电台推理游戏，入口为 `index.html`。复制整个目录可独立运行，没有后端或 AI 请求。本次只更新本地，未发布。

## 本版修改

0.12.1 修复“采用全部已核实材料”缺少选中状态的问题。选中后只有它高亮；切换正面或反面会取消它。手动取消某份材料或断开某轨后，全选高亮也会取消。重开播出单、重载存档会保留正确状态，CUE 与实际节目按所选方式呈现。完整客观播报仍只要求研究和采用完整，不要求额外点击这个选项。

《余声》暂为现有章名，正式标题待定，本版没有另行命名。首页保留单行标题；告示中“再等三天”仍是案件事实。

首章先交代主持人的节目与约访：小春写信希望回应钥匙照片和九秒录音引起的指责，带着原始通话到台里。四段开场依次呈现来信、初次见面、网上切片和完整通话，随后由采访取得后续材料。正式节目补齐欢迎听众、来访背景、段落衔接与道别；CUE 与实际播出使用同一份稿件，只讲本期采用的内容。

“下一句问什么”只放当前可追问的问题。未读原件移到独立收件区，说明提供者、在哪次采访中交付、为何交付；旧存档的材料不再冒充刚收到。钥匙采访只得到钥匙和退住簿，核实旧钥匙后再问奈央当晚如何离开，才得到入口录像。返身录像与伤者记录仍各有后续取得路径。

首次到达“材料已在待播盘”检查页，导播会要求点击 RETURN TO MATERIALS 返回核实，再说明何时才应选择收尾。开启引导时，第一次直接点结局会被阻止；可主动跳过当前教学或关闭引导。

先事后人／先人后事现在会改变开场、段落衔接和听众留言的切入点。两种编排使用同一批材料，不改变结局门槛；只采用一种材料时不提供无意义的顺序切换。CUE 可读到实际过渡文字，播出后稿件按原样封存。

按用户要求，本轮没有扩写独立同行或共情主剧情。

基础与深层推论均保留在可选列表里，已经推过的会显示“已核实”。深层页列出各条结论需要的原件与前置推论。尚待核查只列真实未完成的项目；安置款和伤情边界已经核实后，对应缺项会消失，不再把说明句当作永远待查的任务。

## 四种收尾

好人和坏人的资格主要由 A 轨实际采用的案件材料决定。案件按六个独立主题计权，组内取最高权重，不靠重复推论堆分：流言澄清正1、隐瞒负最高3、款项负3、返身正3、救援处境正1、伤情边界中性。B 轨是一份整体人物侧写。整体正面、整体反面与“采用全部已核实材料”是三个互斥选项，当前所选会高亮并保存。达到两段深入确认经历和一条关系的采用条件后，正面或反面给所选方向加1；采用全部会把侧写两面都说，正反各加1，不按六段经历分别累加。人物关系不重复加分。

正式人物判断至少采用三个案件主题、两段深入且确认的人生经历和一条关系。某面至少3分且不低于另一面的三分之二，才开放该面的定性；混合材料可以同时开放好人和坏人。检查页显示双方分量和缺项。

| 选项 | 作用 |
| --- | --- |
| 好人 | 对整个人作正面定义，计入已定性记录 |
| 坏人 | 对整个人作反面定义，计入已定性记录 |
| 完整客观播报 | 必须全收集，并在本期采用全部必要推论、六段经历、三条关系；选择后自动完整呈现正反两面，不对人物定好坏，属于本章完整客观结局 |
| 材料不足／只播现有摘要 | 明确结束本期，但调查或采用范围尚不完整；不算完整客观结局，不新解锁 CG |

B 轨的六段经历仍可手动取舍。两端经历都已采用时，已核实可用的关联会自动一并带入；取消一端，也会取消依赖它的关联。可一键采用全部“已核实可用”材料；该按钮不发放未知原件、不完成未做的调查。完整采用后，完整客观播报自动可选，不需另点“呈现两面”或逐段切换按钮。

傲慢记录按每名角色最后封存的一版计算：good/bad 为定性，objective 为完整不定性，zero 为未完成。重编同一角色不重复累加。全部人物均被定性为极度傲慢，部分被定性为一般，全部完成客观播报才是不傲慢的完整结果；摘要不能刷这个结果。目前只实现小春章节，记录可扩展到后续人物，不把本章完成冒充整个未制作战役通关。

## 保留功能

B 推理仍为选说法、放来源、一次提交；P 保留六段取材、实际点击／拖放拼图及翻面；N 笔记、H 提示、R 播出单与播出前 CUE 保留。16 岁经历可正常深入，片段不会自动摆入或确认。已有研究可复用，旧播出稿不被后来的发现重写。

测试专用 `TEST / 一键推理` 仍开启。上线前移除 `debug.js` 引用或将 `DebugInference.enabled` 设为 false。
