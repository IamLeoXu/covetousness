# DEAD AIR · 第一章 v0.6.5

静态 HTML5 电台推理原型。复制本目录全部文件（含 assets、execution、.nojekyll）即可部署 GitHub Pages，不依赖其他项目或服务器。

本版区分三个结局：零散摘要为第 0 结局，不解锁 CG；正面与负面定性需要已核实的行为链、两段相关人生、一条关系及正确采用的拼图，并把必要轨道放进节目。无需六段全收集。CG 权限以播出时冻结的论证为准，不能靠事后补查倒解锁。

引导恢复 0.6.0 原版：导播浮层、目标框、箭头和逐步操作教学，包含原件比较、时间与受话人核对、首次组合、补访与人生拼图。黑色遮罩保持 35%。红框跟随目标当前可见范围，避免弹窗入场变换和滚动裁切导致偏移。提示框标题栏从首次出现即标明可拖动，支持鼠标和触摸；位置会保存，后续步骤继续沿用，并限制在可见区域内。标题栏聚焦后也可用方向键移动，Shift 可加快。保留原版收起与关闭引导按钮；菜单的“PRODUCER / 补看操作引导”可重新开始教学。0.6.1–0.6.3 的注释框、停靠行与自动避让方案已撤回。调查与结局状态保留，已关闭引导的偏好继续生效。

CUE 与 ARM 的实际功能保留 v0.5：CUE 文字核对当前组合，ARM 使 REC 待命；修改组合会解除。操作优化和推子只是讨论方案，未实现替换。

B 比较原件，P 人物档案，N 取材笔记，R 播出单，H 提示。详细组合与三个结局路线见 walkthrough.html。旧版存档可继续；旧版低门槛 HOLD / RELEASE 记录视为摘要，保留原稿与调查但不冒充新逻辑链结局。

电话、访谈、播出均为授权文字转录配设备声。小春仍只使用 shadow/detail 无五官素材；CG 歌词、镜头、素材及播放器不变。独立 DEAD_AIR_CG 和旧 DEAD_AIR_INQUIRY_DEMO 本次均未修改。
