# DEAD AIR · 她留下的东西 / 第一章 v0.3

案件调查、独立的人生调查、正反人物拼图、两种终局评价与完整处决 CG。无安装、无构建、无后端、无 AI API。

用 Chrome 或 Edge 打开本目录的 `index.html`。部署 GitHub Pages 时，把本目录内的全部内容（包括 assets、execution 和 .nojekyll）放到站点根目录；不需要两个旧项目或 assets_all。

## 这次的玩法

案件分成三卷：最初指控、危险告知、救援后果。只展示当前卷的物件与材料；原始材料和已核实推论分开切换。当前卷最多七份原始材料，单个地点最多四件物件，完成后依次展开下一卷，仍能返回旧卷核对。

人生侧写独立调查，不把私人经历塞进定罪证据池。六段分别涉及家庭迁居、恋爱、职业选择、分手、友情与家庭关系的变化。每段需读旧档、选问题补访、比对两份来源并重建事件；随后将事件用于三条关系推断，最后完成时序拼图与正反阅读。侧写和案件都完成后才开放终局。

所有小春的可见立绘、对话与拼图都使用已有 shadow/detail 无五官素材；不新增恋人的人物立绘。游戏的石墨色、荧光绿、紫色和红色保留。

处决播放台的手动 STOP、自然播完后的自动 STOP 与退带，共用待机黑屏：保留暗磷光底色、固定细颗粒、扫描纹理与玻璃反光。自动停止后不再持续雪花或磁带底噪；退带与开盖的机械演出保留。PLAY 暂停仍保留当前画面。

## 操作与攻略

B 案件组合，N 分类笔记，P 人生调查，H 分阶段提示，1 / 2 / 3 切换地点，Esc 返回，Enter 继续对白。触屏可点击完成操作。进度自动保存。

- `walkthrough.html`：每一卷的材料组合、六段人生的补访与重建答案、三条关系、拼图顺序及两种结局。
- `case-notes.html`：原创案件时间线、人物经历、真实判例的创作参照与边界。

已有 v0.2 存档可继承案件收集与推断；新增的人生调查需要完成，旧终局不会跳过新内容。旧存档键保留，v0.3 使用独立存档键。

调查录音、访谈与录像以标明来源的文字摘录呈现；处决 CG 包含完整歌曲、人物动画、真实波形与设备音效。

## 文件独立性

增量仅在本目录。原 `DEAD_AIR_CG` 和 `DEAD_AIR_INQUIRY_DEMO` 不改动。完整 CG 与依赖在 execution 内；调查使用的背景、物件在 assets 内，剪影直接复用 execution/assets/character 内的文件，没有上级目录依赖。

被替换的根目录人物图片和此前代码已归档到工作区 assets_all/checkpoints/chapter-before-v03，不属于网站依赖。验证脚本和截图也在 assets_all，不需要上传。
