# DEAD AIR · 余声 / 第一章 2.0.0

你是 FM 107.9 深夜节目《AFTER HOURS》的主持人。天音小春带着一封来信和完整通话来到电台，希望回应网上的一张照片与九秒录音。询问相关的人，核对原件，决定最后让听众听见什么。

## 开始游戏

入口为 `index.html`。保留整个目录的文件结构，游戏会自动保存调查进度。重新开始会清除当前调查；已经封存的节目可在记录中回看。

## 操作

| 按键 | 功能 |
| --- | --- |
| B | 推理：选择说法，用原件与已核实推论支持它 |
| P | 人物侧写：询问经历、阅读来源、拼合年代 |
| N | 笔记：查看已核实结论与尚待核查的问题 |
| R | 播出单：选择材料、调整先后、预听与准备播出 |
| H | 查看当前步骤的提示 |

推理界面的“一键推理”是常驻辅助功能，会列出本卷已读来源能够支持的结论。点选即可填入材料并提出追问，也可以自行组合来源。

## 准备本期节目

新材料随着询问取得，收到后还要打开阅读。六段人物经历需要核对来源，再把片段放回对应年龄；两段已经确认的经历会连成人物关系。

A 轨采用案件材料，B 轨采用人物经历与整体侧写。整体正面、整体反面和“采用全部已核实材料”是互斥选项；采用全部时会保留侧写两面。手动选齐材料同样可以完整播报。

CUE 是本地预听。首次到达播出检查页后，按提示 RETURN TO MATERIALS 返回继续核实；准备好结束本期时，再选择最后一句并播出。

## 四种收尾

- 好人：本期采用的正面材料充分，对小春整个人作正面定义。
- 坏人：本期采用的反面材料充分，对小春整个人作反面定义。
- 完整客观播报：完成调查，并采用全部必要案件与人物材料，正反都说，不给她定好坏。
- 材料不足／只播现有摘要：以当前选入的片段结束本期。

已经封存的稿件保留原样。继续核查或重新编排时，已有调查可以复用。

完整剧透见 `walkthrough.html`，节目档案见 `case-notes.html`。项目更新记录保存在上级 `assets_all/PROJECT_LOG.md` 与 `assets_all/UPDATE_v2.0.0.md`。
