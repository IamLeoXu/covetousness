# DEAD AIR · 第一章 v0.8.1

静态 HTML5 电台推理原型。复制本目录全部文件（含 assets、execution、.nojekyll）即可部署 GitHub Pages，不依赖其他项目或服务器。

调查与播出分开保存。原始材料先用于核实推论；已核实结果永久保留，可再次参与组合，也能从素材库送入 PGM。三类深层结论不能用原始线索直接跳过：未完整告知、救援处境、因果边界。各项推论会显示依据和后续用途。

上方 A/B/C 切换问题卷宗；下方 1/2/3 是当前说法的来源位。两组没有配对关系，来源顺序不限，不必填满。新手引导会先解释，再带着完成第一个组合；原件和推论可混用，切换标签保留已选材料。

R 播出单按 A1、A2、A3、B 分轨。展开素材库选择案件推论或人物解读，再接入 PGM。断开轨道或更换内容不删除调查，也不需要重做 REC 或补访，只需重新 CUE 确认本期版本。人物解读会自动带入两段依据，也可一键替换 B。

人物片段按日期在拼图确认一次后永久入库。之后编辑拼图不抹去此前的确认，节目选择独立进行；完整侧写也可继续查看、编辑。只读过表面档案的片段可用于摘要；正式定性仍需要深入重建的相关两段与一条人物推断。

最后审判只计算实际选入本期的推论和人物链，未采用的已知内容不会自动计入。链不足可做第 0 结局；正面和负面定性分别需要对应的完整论证，不要求六段全收集。播出完成后可用现有素材另编一版，不必重新调查；旧版原稿、封存论证与已经获得的磁带权限保留，后续发现不能倒写旧摘要。

CUE / ARM / REC 仍用于提出新追问。已有素材直接选用即可。保留 0.6.0 风格的逐步导播引导、35% 遮罩、红框和可拖动提示框；标题栏首次出现即提示可拖动，位置自动保存。

B 比较原件，P 人物档案，N 笔记，R 播出单，H 提示。完整组合及两个正式结局见 walkthrough.html。0.6.5 及更早存档可继续，已核实内容与已采用侧写会迁移，不要求重做。

角色继续使用 shadow/detail 无五官素材，常态改为去钥匙版，原图保留。嵌入 CG 与独立 DEAD_AIR_CG 同步新增十二幅物件记忆和风格化切镜（v0.28），保留原有歌词、场景、走路与 MOV 踩点。旧 DEAD_AIR_INQUIRY_DEMO 不变。

本版明确区分以下入口：

| 入口 | 任务 | 留下什么 |
| --- | --- | --- |
| 比较原件 / B | 原始材料与已核实推论继续组合 | 有来源的案件推论 |
| 和小春谈谈 | 值班间隙交流，认识手艺、性格和关系 | 对话记录；不自动变成定性证据 |
| 人生档案 / P | 原档、附页、正式补访、关系连接、年代拼图 | 核实的经历与人物推断 |
| 播出单 / R（RUNDOWN） | 从现有素材库挑本期采用的内容 | 实际接入 PGM 的播出版本 |
| 取材笔记 / N | 查阅已知与尚未核查的部分 | 调查记录；不替你选播 |

“全部材料”原名“混合”，只是同时显示原件和推论的筛选视图，没有额外证据规则。拼图只核对经历年代；B 轨主要选择人物解读，一次选择自动带入相关两段经历，不再重选同一对拼图或另选补访引语。只播个别经历，可展开“散段摘要”，它不等于完整人物论证。

所有弹窗对话提供“上一页”，也可按 ← 回看。回退不撤销调查，不重复执行结尾行为。菜单“回看刚才的对话”可重读最近读完的文本，不重放游戏效果。对话专题的首句可退回问题选择。

两个正式结局在 OFF AIR 对话中由小春亲手递出磁带，切到与 CG 播放机一致的磁带特写。结局页直接显示磁带和“播放结局 CG”；第 0 结局没有新磁带。

引导由实际打开的模块触发：案件初次组合、谈谈、经历调查、关系连接、拼图、笔记和播出单分别教学。做完第一条案件推论后不强制去侧写。可跳过当前模块，或关闭全部，保留原有红框、35% 遮罩和拖动功能。

CG 新记忆包括针线、橱窗、修衣、杯子、车票、门、匿名相框、伞、餐桌、寄件、电话和信封。在 112–135.5 秒原有 80 个硬切踩点中，通过双联、斜切、三联、嵌图和局部构图接镜，不加入小春的脸或身体；减弱动态选项保留。
