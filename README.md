# DEAD AIR · 再等三天 / 第一章 v0.10.0

静态 HTML5 电台推理游戏。入口是 `index.html`，本目录包含全部运行资源；复制整个目录即可独立运行。没有后端或 AI 请求。本次只修改本地，未推送或发布。

## 这一版修正了什么

上一版 16 岁经历没有完成路径，人物拼图被独立同行流程替换。本版恢复六片真实拼图，并把材料取得接回采访。

开场只有来访者实际带来的帖子、切片和完整通话。玩家追问后，奈央提供报警受理页与旧钥匙的出处；澄清一项指控后，她提出告示的问题。小春被问及维修判断才拿出报告，被追问安置款才出示转账。返身记录、接线后段、伤者的交接页与随访说明分别沿问题取得。未取得的原件不会摆在场景或可直接打开。

不再有独立“同行打卡”。人物在提供材料、回避问题、打断或补充对方时参与调查。私人经历也在短采访中说明谁拿出旧物、谁留下回答；没有初始摆满全部私人档案。

## 操作

- 采访桌：选择当前有理由继续问的问题。采访结束后材料交到台内，主材料直接打开；其余收到但没读的文件留在“刚交来的材料”。
- B 推理：选说法，放入最多三份来源，点一次“推理 / 提出追问”。已核实推论仍可参与深层组合。来源顺序不限，第三位可以留空。
- P 人物侧写：六段都可取材，包括 16 岁。听完采访收到来源，打开两份原件后核对经历，得到拼图片段。点击选片再点对应年龄，或拖放；核对年代后保存。相关两段自动形成关系，不再另做关系选择题。
- 拼图可翻正反面。同一段经历的不同读法会进入本期 B 轨，并影响好人／坏人审判资格。部分相关片段就能支持相应审判，不要求六段全收集。
- R 播出单：勾选推论即采用到该轨；选择人物关系会同时带入两段依据。CUE 查看本期稿件，最后签署好坏判断。更换内容只需重新 CUE，不重做取材和推理。
- N 笔记，H 分步提示。菜单可重开引导和回看已完成对话。

调查和本期采用分别保存。没有选入的已知内容不参与本次审判。稿件与来源在播出时封存，可用现有研究另编一版；后来的发现不会重写旧节目，也不会升级旧摘要的 CG 权限。

## 测试专用一键推理

B 界面的 `TEST / 一键推理` 会直接列出当前卷已读来源能推出什么，并显示具体组合；点击其中一项可直接填入并提交。不会发放未取得的原件，也不会跳过深层推论所需的前一层结果。

此功能当前开启，供用户测试。上线前删除 `debug.js` 的 script 引用，或把该文件中的 `DebugInference.enabled` 设为 `false`。本版没有发布。

## 审判与侧写

结尾恢复对整个人作“好人／坏人”的公开定性。玩家选择真实材料的一部分和人物正反读法，进而给她整个人命名；角色的短反应保留这种判断带来的距离，为后续玩家傲慢支线留出空间。没有用“有限信任”把玩家的裁决预先写成无可指摘。

第 0 结尾保留摘要收尾。两个正式结尾仍需对应案件与人物最小链。音频磁带从开场留在桌上，结尾封存本期录音；CG 本体不变。
