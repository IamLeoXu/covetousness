# 磁带与插带开场 / v0.13

入口不再是画面里的播放按钮。点击小春的实体磁带后，先移入播放器舱位，再合上门，最后将镜头拉远，落到当前界面的左侧磁带。音乐在这三步结束后才从 0 秒开始，歌词时间不需要加偏移。

timeline.js 的设置：

```json
"cassette": {
  "title": "KOHARU",
  "subtitle": "FALLING FLOWERS",
  "decal": "assets/ui/koharu-tape-decal.png"
}
```

```json
"intro": { "insertMs": 850, "closeMs": 520, "pullbackMs": 1050 }
```

intro 位于 settings 中，单位毫秒。合计约 2.42 秒，只影响开场动效；开场完成后停止 / 回放不会再插一次磁带。设备减少动态效果时跳过空间运动。连续点击磁带只执行一次，歌曲还会等待音频准备完成。

cassette.js 统一绘制开场与界面的同一盘磁带。外壳深梅、奶油与玫瑰配色，PNG 贴花使用绘制的蝴蝶结、信封和心形钥匙。PNG 用于保证 SVG 内嵌图片的兼容性。

两卷盘固定在同一 viewBox 坐标 (100,107) / (220,107)，不分别使用 CSS 的百分比定位或 scale。外卷径随带量一增一减，轴心不移动。带路从卷盘切点经过左右导带柱、塑料壳边缘和底部读头口，细线为 0.85，读头口处仍保留带路。

改开场动效位置与舱盖外观看 opening.js / style.css；改主界面磁带结构与卷径看 cassette.js。使用像素坐标与等比 SVG，避免单独拉伸其中一组卷盘。
