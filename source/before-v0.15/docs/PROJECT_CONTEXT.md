# 后续修补 / v0.14

入口 index.html，H5 深夜电台悬疑审判游戏的贪婪支线 CG。保留甜美年轻女性的原设计、长发与大蝴蝶结，采用硬朗黑线、深梅 / 旧玫瑰 / 奶油色的图形剪影画风，不改成写实、柔光厚涂或成熟脸。用户认可遮面风格，但明确反对玫瑰色的腿和短腿。v0.14 抬手按原来的盘腿姿势处理：双膝向外，小腿自然交叠，露肤统一浅桃色；痛哭同步浅肤色，新增完整盘腿握信。默认演出不再堆半身特写，不覆盖旧素材、已有七张高清图或原图。

电台、磁带、耳机不是女主的身份特征。磁带因记录她而采用她的配色和信封、蝴蝶结、心形钥匙贴花，外部播放机和 UI 保持游戏配色。精确机械 UI 用同一坐标的 SVG；角色与图形素材使用绘制图片，不用代码画人物或背景插画，不画触须。

初次进入点击实体磁带，按放入、合盖、拉远三阶段进入播放器。歌曲在开场完成后才从 0 开始。重复点击不触发两次插带，后续播放 / 停止不会重新插带。系统减少动态效果时跳过空间运动。

保留 38 组订正歌词、time / end、原曲与用户 0–31 秒四个手动节点。69–77 秒用旧黑脸 / 遮眼人像在画框中加速闪回；77 秒 Wind in the wires 必须硬切到旧 blackStrings 电线背景，不让人像多停留半秒。112–135 秒 instrumental 用 scene.flashbacks 的 15 个切点，改用完整坐姿、前段画面、物件和空场；静态人物默认完整图，仅显式 framing: "portrait" 使用旧半身排版。撤掉 STAY / KEEP 大字。

faces 始终遮挡或黑脸，不具体化歌词中的 you，不新增对方人物或背影。原有 52–61 秒与 solo 里对应的短暂无歌词温暖回忆可使用笑脸，失落歌词继续用遮面剪影。

撤销 REVEAL / SHIFT 及其交互显影层。下方推子变为字幕字号和画面亮度，音轨只经过主音量，真实 VU / 波形 / 相位图继续随音乐时钟。所有演出配置在 timeline.js，不添加调试界面。

当前检查采用真实素材 Native Canvas、DOM / 动画状态与 SVG 几何测试。浏览器启动因环境 socket 限制失败，未宣称完成浏览器实播或扬声器试听。
