# 后续修补 / v0.15

实际项目在用户指定的 Windows DEAD_AIR_CG 内。所有运行素材、绘制原图和参考必须保留在该目录。复制整个目录后无需引用 work、outputs、C 盘其他素材目录或在线图片。无需构建。用户自行推送 GitHub，本轮未推送。

人物故事以 GREED_STORY_DRAFT.md 为准，简明设定见 CHARACTER_BRIEF.md：年轻甜妹经营共助小楼，把拯救与付出逐渐变成无法放手的占有。钥匙、账簿、住客纸条、遗留杯子是人物符号。电台、耳机和磁带属于叙事设备。

沿用用户认可的长波浪发、蝴蝶结、落肩外套、短裙和靴子，无编发。硬黑线、平涂、硬阴影，保持图形化游戏风格。角色及 CG 用深梅、旧玫瑰、象牙色；UI 用游戏的紫黑、黄绿、淡紫。v0.15 抬手图保留原上身，腿部改自然侧收跪坐；四张遮面人物露肤统一中性象牙与米褐阴影，禁用玫瑰色腿。旧素材不覆盖。

角色、背景与旧物使用绘制图片；不以代码画人物、插画背景或触须。机械 UI 可用统一坐标的 SVG。照片 faces 黑脸或遮脸；不具象化歌词中的 you，不新增陌生人或背影。

常规静态人物默认完整图，按 scale / x / y 排版。112–135 秒 Solo 恢复 15 个闪回切点，使用握信、空抱、掩面、抬手、握钥匙特写，穿插前段回放、无脸照片及旧物。特写在 flashbacks.layers 编辑，不因其半身而替换普通场景素材。170 秒起完整握钥匙坐姿进入纸框，193 秒后只剩旧物。

保留 38 组订正歌词、time / end、原曲及用户 0–31 秒手动节点。69–77 秒用旧黑脸画框加速闪回，77 秒 Wind in the wires 必须切到 blackStrings。笑脸仅在无歌词的温暖回忆使用；撤掉 STAY / KEEP 大字。不要逐句机械换背景。

初次进入按插带、合盖、拉远三阶段开始；歌曲从流程结束后开始。暂停、倒带和重复点击逻辑保留，减少动态效果时跳过空间运动。

两个推子为 ARCHIVE / OBJECTS 和 ERASE / PEOPLE。前者保存旧物，后者抹去人形但保留独立物件、画框与背景；默认 0，可同时推进，暂停也响应。音轨只经 MASTER，推子不影响歌曲或字幕时间。界面文本、提示和无障碍标签使用英文。字幕字号在 JS 的 settings.lyricFontScale 编辑，不设调试界面。

本轮检查使用真实素材 Native Canvas、生产 DOM / 动画状态测试及 SVG 几何测试；浏览器启动在应用容器 crashpad 阶段失败，未完成浏览器实播或扬声器试听。详情见 VALIDATION.md。
