# 小春的角色设定 / v0.15

天音小春 / Amane Koharu 为工作名，年龄二十多岁。案情依据同目录 GREED_STORY_DRAFT.md；具体地名、其他责任人和最终归责仍以正式剧本及证据为准。

她经营旧街的一栋共助小楼，为人提供暂住处。外表甜，记得住客的习惯；做事能扛，会和维修商讨价还价。为了保住小楼，她卖过自己的东西、接额外工作，把钱补进租金和维修。

她逐渐不能接受离开：想同时留下房子、住客、过去的付出和自己努力的意义。新的整改要求到来后，她把临时安置的钱继续投入经营，并压住停用建议。事故造成住客受伤、分散，她来到电台接受复核。不要擅自改成故意杀人，也不要让 CG 替尚未确定的证据下结论。

她的标志物是小楼钥匙、维修与租金账簿、收起的住客纸条、遗留杯子和合影。录音、磁带、耳机属于电台的叙事设备。记录她的磁带可以借用她的配色与图案。

外貌沿用用户认可的年轻甜妹版本：长波浪发、侧边大蝴蝶结、交叉发夹、心形耳饰、落肩外套、短裙和靴子，无编发。画风使用硬黑线、明确的平涂与硬阴影；甜美长相与图形化画风同时保留。角色及 CG 用深梅、旧玫瑰、象牙色；外部 UI 继续采用游戏的紫黑、黄绿、淡紫。

剪影中的脸无五官。露肤使用中性象牙色和米褐阴影，玫瑰色留给头发与服装。人物姿态要有清楚的关节和腿长；抬手图本版保留上身，改成向一侧收拢的跪坐。

CG 的处决反讽：她终于保存了所有物件，人与这些物件之间的关系却被抹去，最后她自己也成为封存品。ARCHIVE 留下旧物，ERASE 抹去人形，两者可以同时推进。它们是演出操作，不新增案情或改变剧情判定。

住客照片和歌词里的 faces 一律使用黑脸、遮脸或空像。歌词中的 you 不具体化，不新增一个陌生人或背影。挽留用她伸向画外的手、空抱和窄光表达。不使用触须、藤蔓或来历不明的人物。
