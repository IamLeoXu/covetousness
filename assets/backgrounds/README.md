# 图形背景

五张独立的 1774×887 背景，采用玫瑰、奶油、深梅与旧金色。项目使用无损 WebP；人物、字幕、画框和物件在 Canvas 中独立叠加。

| 文件 | 意象 |
|---|---|
| petal-road.webp | 折纸弯路与悬停的落花 |
| paper-vault.webp | 折叠的纸、空位与不肯放手的收藏 |
| empty-windows.webp | 飞逝的空车窗与无名记忆 |
| black-strings.webp | 黑线、混凝土碎片与触不到的窄光 |
| morning-vault.webp | 封存的空位与未能挽回任何人的晨光 |

空画框内没有新人物或面孔。使用与替换方法见 ../../docs/BACKGROUND_MOTION.md。
