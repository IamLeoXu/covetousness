# 角色素材

native、seated、stand.png 来自用户给的两张原图。六种坐姿从拼图独立切出，一张站姿去黑底；这些原始切片未重画。native 为原始像素尺寸，seated 与 stand.png 为 2 倍等比放大，sources 保留原附件。

assets/portraits 是旧的按面部锚点裁切的半身排版；v0.14 需显式 framing: "portrait" 才使用。原源图哈希、裁切框与锚点见 manifest.json。

hd 为后来清线的七张完整立绘。shadows 为按角色设计补画的遮面姿势，v0.14 使用 reach-shadow-v14.webp、sob-shadow-v14.webp、letter-sit-v14.webp：完整坐姿，浅桃肤色。旧素材保留。details 是旧半身特写，默认时间轴不再调用。
